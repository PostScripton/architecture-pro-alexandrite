# architecture-pro-alexandrite

Проектная работа 6 спринта курса «Программный архитектор» от Яндекс Практикума.

Кейс: компания «Александрит» - производство ювелирных украшений на заказ. Задача - решить проблемы с производительностью и наблюдаемостью системы.

## Структура

- `project_overview.md` - описание кейса и архитектуры компании
- `how_to_complete_project.md` - требования к сдаче работы
- `Task1/` - Анализ, идентификация проблем и решений, планирование
- `Task2/` - Мониторинг
- `Task3/` - Трейсинг (+ Задание 3.1 с OpenTelemetry и Jaeger)
- `Task4/` - Логирование
- `Task5/` - Кеширование
- `images/` - общие картинки кейса (C4-диаграмма и др.)

## Как сдавать

Работа сдаётся через пул-реквест. Подробнее - в `how_to_complete_project.md`.
